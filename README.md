# NimbleCat — website prototypes

Four animated homepage directions for [nimblecat.co.nz](https://nimblecat.co.nz).

**Live:** https://shaunnez.github.io/nimblecat-prototypes/

| | Prototype | Stack |
|---|---|---|
| 01 | [Prowl](https://shaunnez.github.io/nimblecat-prototypes/p1-prowl/) — kinetic typography | GSAP, ScrollTrigger, SplitText, Lenis |
| 02 | [Nine Lives](https://shaunnez.github.io/nimblecat-prototypes/p2-ninelives/) — immersive WebGL | Three.js, GLSL, GSAP, Lenis |
| 03 | [Night Walk](https://shaunnez.github.io/nimblecat-prototypes/p3-nightwalk/) — cinematic scroll story | GSAP, ScrollTrigger, SVG, Lenis |
| 04 | [Night Walk II](https://shaunnez.github.io/nimblecat-prototypes/p4-nightwalk-ii/) — Night Walk with work first, clean load, legible hero | GSAP, ScrollTrigger, SVG, Lenis |

Each prototype is a single static `index.html`. Run locally with `python3 -m http.server` from the repo root.
